# ✨ Overview

**Aethoria: Eternal Realms** is a fully custom MMORPG engine and editor.

Every system is written manually:
- rendering
- AI
- animation
- world logic

> This is not a framework.  
> This is a real engine.

---

## 🎮 Features

### Engine
- ⚔ Real-time combat
- 👾 AI states
- 🗺 Tile world
- 🎬 Animation system
- 🔊 Audio
- 🌐 Scene system
- 💾 Save/load

### Editor
- 🖌 Map editor
- 👺 NPC placement
- 📦 Prefabs
- 🎭 Dialogue system
- 🔄 Auto-sync
